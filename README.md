# Customer Sales Data Analysis

## Overview

This project focuses on cleaning and analyzing a customer sales dataset using Python and Pandas.

## Tools Used

* Python
* Pandas
* Jupyter Notebook

## Key Tasks

* Loaded and explored the dataset
* Handled missing values
* Removed duplicate records
* Cleaned and standardized text data
* Converted data types
* Created a Total Sales column
* Performed sales analysis using GroupBy and aggregation
* Exported the cleaned dataset to CSV

## Analysis

The cleaned data was used to analyze:

* Total sales by product
* Sales and order count by city
* Customer ratings by city

## Files

* `Customer_dataset_cleaning_code.ipynb` – Python analysis and data cleaning
* `customer_sales_messy.csv` – Raw dataset
* `Customer_Dataset_cleaned.csv` – Cleaned dataset
